## 🚀 Featured Projects

### BTP & MTP — HierRoad: Hierarchical Video-Language Benchmark *(Ongoing)*
- Developing a multimodal benchmark for reasoning in unstructured traffic environments.
- Curated **3.5K+** ego-centric driving clips with expert summaries, VideoQA and temporal annotations.
- Designing hierarchical tasks for temporal reasoning, anomaly detection and vehicle Re-ID.
- Evaluating state-of-the-art Vision Language Models (VLMs) for multimodal traffic understanding.

---

### [Pathology Image Classification & WSI Analysis](https://github.com/KondetiAravind/PathoVerse-AI)
- Developed tumor classification for pathology tiles using **UNI, GigaPath and CONCH** models.
- Evaluated 1,400 PCam samples total, GigaPath reached **92% accuracy** and 0.975 AUROC overall.
- Processed 45 WSI tiles with **Attention-MIL**, achieving 1,483 tiles/s at 0.67 ms/tile inference.
- Built **WSI analysis** using OpenSlide, MONAI and PyTorch, with retrieval reaching **21.1% R@5**.

### [⚡FoodPulse - Restaurant Recommendation & Experimentation](https://github.com/KondetiAravind/FoodPulse)
- Targeted **40% faster Time-to-Order** for 50K+ users through improved discovery and conversion.
- Built **hybrid recommender** using 40/35/25% CF, content and context for 500 restaurant rankings.
- Analyzed 436K+ orders and 310K+ interactions through **7 ranking metrics** and **cold-start flows**.
- Designed **A/B testing** with 50/50 allocation, 10K users/group, α=.05, 80% power and 20% MDE.

### [🎟️ Book Your Show — Full-Stack Movie Ticket Booking Platform](https://github.com/KondetiAravind/Book_Your_Show-Full_Stack-Movie_Ticket_Booking_Platform)
- Built **full-stack movie booking platform** using Flask with 15+ REST APIs and modular Blueprints.
- Engineered **seat selection and booking workflows** supporting 100+ seats per show.
- Implemented **session-based authentication**, dynamic pricing and heuristic best-seat recommendations.
- Deployed production backend on **Render** with 10+ relational tables and automated database seeding.
