## 🚀 Featured Projects

### 🚗 HierRoad — Hierarchical Video-Language Benchmark *(Ongoing)*
- Developing a multimodal benchmark for reasoning in unstructured traffic environments.
- Curated **3.5K+** ego-centric driving clips with expert summaries, VideoQA and temporal annotations.
- Designing hierarchical tasks for temporal reasoning, anomaly detection and vehicle Re-ID.
- Evaluating state-of-the-art Vision Language Models (VLMs) for multimodal traffic understanding.

---

### 📄 RAG-based AI PDF Chatbot
- Built a full-stack semantic PDF chatbot using **LangChain, LangGraph and Next.js**.
- Implemented dual LangGraph workflows for document ingestion and retrieval.
- Integrated **OpenAI** with **Supabase Vector Store** for context-aware question answering.
- Developed a responsive chat interface with streaming responses and source-backed citations.

---

### 🎬 Sentiment Analysis on Movie Reviews
- Built a **RoBERTa-based** sentiment classifier for **156K+ IMDb reviews**.
- Fine-tuned the model to achieve **69.5% Accuracy** and **0.62 Macro F1 Score**.
- Developed PyTorch data pipelines, tokenization and evaluation workflows.
- Deployed the application using **Streamlit** for real-time sentiment prediction.
